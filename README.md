## Geothermal Volumetric Calculator

This repository includes `geothermal_volumetric_montecarlo.py`, a Python script for estimating recoverable geothermal power. The calculator uses Monte Carlo sampling with triangular or constant distributions based on the provided parameter ranges. Results are summarized as P10, P50, and P90 power levels and displayed on a cumulative probability chart.

### Requirements
- Python 3
- numpy
- matplotlib

### Usage
1. Adjust the parameter ranges in `geothermal_volumetric_montecarlo.py`.
2. Run `python3 geothermal_volumetric_montecarlo.py` to print the P-values and show the plot.
